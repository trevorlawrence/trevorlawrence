### 🔧 [DISA STIG Remediation & Compliance](https://github.com/trevorlawrence/DISA-STIG-Implementations)

Hands-on implementation and validation of **DISA Security Technical Implementation Guides (STIGs)** on Windows 11 systems. Includes PowerShell-based remediation, manual implementation procedures, and compliance validation using Tenable.

The project includes **CAT I, CAT II, and CAT III** Windows 11 STIG remediations.

**Technologies:** PowerShell · Windows 11 · Tenable · Group Policy · DISA STIGs
